## 🌟 वैशिष्ट्ये (Key Highlights)

- 🚫 **कोणतेही लॉगिन आवश्यक नाही (Zero Login Requirement):** शिक्षक किंवा विद्यार्थी कोणत्याही अडथळ्याशिवाय एका क्लिकवर प्रश्नपत्रिका वापरू शकतात.
- 📋 **अधिकृत उत्तरपत्रिका हेडर (Official Exam Header):** विद्यार्थ्याचे संपूर्ण नाव, हजेरी क्र., इयत्ता, तुकडी, दिनांक आणि शिक्षकांसाठी **प्राप्त गुण (Marks Obtained)** चौकट.
- ✍️ **हस्ताक्षरासाठी आखलेल्या प्रशस्त ओळी (Spacious Ruled Writing Lines):** प्रत्येक प्रश्नाखाली उत्तरे लिहिण्यासाठी सुस्पष्ट आखलेल्या रेषा व बहुपर्यायी प्रश्नांसाठी उत्तर चौकटी (`[ उत्तर पर्याय: _____ ]`).
- 🎨 **प्राथमिक स्तरासाठी व्हिक्टर आकृत्या व लेबलिंग (Std. 1 to 4 Visual SVGs):** लहान मुलांसाठी उच्च दर्जाची संगणक चित्रे, कीबोर्ड/CPU भाग ओळखून लेबलिंग करण्याचे प्रश्न (प्रत्येकी **१० गुण**).
- ⚖️ **माध्यमिक स्तरासाठी 'किंवा' पर्याय (Std. 5 to 10 'OR' Choices):** बोर्ड परीक्षेच्या धर्तीवर लघुत्तरी व दीर्घोत्तरी प्रश्नांमध्ये विद्यार्थ्यांना अंतर्गत पर्याय (**'किंवा' / OR**) (प्रत्येकी **२० गुण**).
- 🖨️ **मुद्रणयोग्य (Print-Ready A4 Format):** आधुनिक Vanilla CSS मुळे A4 शीटवर प्रिंट करताना नेव्हिगेशन बार आपोआप लपवला जातो आणि स्वच्छ कागदी प्रश्नपत्रिका तयार होते.
- 🌐 **द्विभाषिक रचना (Bilingual: Marathi & English):** आश्रमशाळेतील सर्व विद्यार्थ्यांच्या सुलभ आकलनासाठी प्रत्येक प्रश्न व पर्याय मराठी आणि इंग्रजीत उपलब्ध.

कोणत्याही अतिरिक्त डिपेंडन्सी किंवा सर्व्हरची आवश्यकता नाही:
1. `index.html` फाईल कोणत्याही आधुनिक वेब ब्राउझरमध्ये (Chrome, Edge, Firefox) उघडा.
