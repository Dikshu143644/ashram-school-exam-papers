## 🌟 वैशिष्ट्ये (Key Highlights)

- 🚫 **कोणतेही लॉगिन आवश्यक नाही (Zero Login Requirement):** शिक्षक किंवा विद्यार्थी कोणत्याही अडथळ्याशिवाय एका क्लिकवर प्रश्नपत्रिका वापरू शकतात.
- 📋 **विद्यार्थी माहिती बॉक्स (Minimal Header):** फक्त **विद्यार्थ्याचे नाव (Student Name)**, **हजेरी क्र. (Roll No.)**, आणि **इयत्ता (Std)**.
- 🖨️ **मुद्रणयोग्य (Print-Ready A4 Format):** आधुनिक Vanilla CSS मुळे A4 शीटवर प्रिंट करताना नेव्हिगेशन बार आपोआप लपवला जातो आणि स्वच्छ कागदी प्रश्नपत्रिका तयार होते.
- 🌐 **द्विभाषिक रचना (Bilingual: Marathi & English):** आश्रमशाळेतील सर्व विद्यार्थ्यांच्या सुलभ आकलनासाठी प्रत्येक प्रश्न व पर्याय मराठी आणि इंग्रजीत उपलब्ध.
- 📈 **इयत्तानिहाय काठिण्यपातळी (Std. 1 to 10 Progressive Difficulty):**
  - **इयत्ता १ ली ते ४ थी:** ओळख, भाग, इनपुट/आउटपुट संकल्पना (२० गुण)
  - **इयत्ता ५ वी ते ८ वी:** संगणकीय कार्यप्रक्रिया, ॲप्लिकेशन वापर, प्राथमिक AI (३० गुण)
  - **इयत्ता ९ वी ते १० वी:** प्रगत संगणक, Machine Learning, AI जबाबदार वापर व केस स्टडीज (४० गुण)
